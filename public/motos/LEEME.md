# Fotos de las motos

Poné acá la foto de cada modelo con el nombre `<slug>.jpg`.

El slug de cada moto está en `data/motos.ts`. Por ejemplo:

- `honda-cb-300-twister.jpg`
- `gilera-smash-125-cbs.jpg`
- `motomel-skua-250-base.jpg`

Mientras un modelo no tenga su foto, la web muestra un placeholder con la marca.

Recomendado: JPG de ~1200×900 px, menos de 300 KB.
